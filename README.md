# under-the-hood

평소에 쓰던 개념들을 이해하고 사용하기 위해 구현을 연습해본 레포지토리입니다.

> 완성된 튜토리얼이 아니라 학습 과정을 그대로 남긴 기록입니다. 그래서 내용이 완결되지 않았거나 이해가 부족해 틀린 부분, 아직 정리 중인 대목이 그대로 담겨 있을 수 있습니다.

## 주제별 기록 포맷

1. **알고 있던 것** — 시작 시점에 알던(안다고 생각한) 것
2. **파고들며 궁금해진 것** — 실제로 붙잡고 있었던 질문
3. **직접 구현** — 코드 또는 CodeSandbox 링크
4. **구현하며 알게 된 것**
5. **막혔던 부분** — 틀린 가설, 헤맨 지점 포함
6. **다음 단계** — (있으면) 이어서 파볼 것
7. **실무에서 어디에 쓰나**
